## Writing & visual blocks

Articles and references are plain Markdown. The site renderer supports two
visual fenced blocks:

- ` ```topology ` — architecture/flow diagrams (JSON). Guide:
  [docs/topology-guide.md](https://github.com/iMoon07/imoon07.github.io/blob/main/docs/topology-guide.md)
  in the site repo.
- ` ```alur ` — animated explainer visuals: many cable styles, motion effects,
  and live protocol/algorithm modules (JSON). Guide:
  [docs/alur-guide.md](https://github.com/iMoon07/imoon07.github.io/blob/main/docs/alur-guide.md)
  in the site repo.

`blog-post-template/` is the Markdown render-test post. It stays Markdown-only:
engine JavaScript lives in `imoon07.github.io/js/alur/`, never here.
